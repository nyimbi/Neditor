# NEditor 0.2.0

First public release of the workbench. Successor to the internal 0.1.0 preview.

Local-first, AI-assisted Markdown workbench for planning, drafting, reviewing, exporting, and publishing business documents.

## Highlights

- **Cross-platform**: macOS (universal aarch64 + x86_64), Windows, Linux.
- **Editor**: CodeMirror 6 with 27 languages, folding, decorations, focus mode, Zen mode.
- **Preview**: live debounced, split/preview-only/source/focus modes, 6 bundled themes plus user CSS with hot reload.
- **Compiler**: front matter + variables + filters, includes, source maps, transforms, formulas, citations (APA, MLA, Chicago author-date + notes, Harvard, IEEE, Vancouver, ACM, ACS, Nature), bibliography, glossary, index, cross-references.
- **Transforms**: Graphviz, D2, PlantUML, Pikchr (full grammar), Mermaid, Vega-Lite, STL (3-point lighting), TopoJSON (antimeridian-safe), GeoJSON, OpenAPI, JSON Schema, timelines, tables, chart designer.
- **Exports**: HTML, PDF, DOCX, PPTX, Markdown bundles, LaTeX, blog/Substack/Ghost/WordPress/Google Docs handoff packages.
- **Copy targets**: Copy as HTML and Copy as Rich Text into any pasteboard-aware app.
- **AI**: provider-agnostic runtime, paste cleanup, voice-guided drafting, humanizer.
- **Governance**: review comments, change notes, snapshots, Git integration, release readiness aggregation.
- **macOS integration**: `neditor://` URL scheme, NSServices provider, AppleScript dictionary, menu-bar helper with warm webview, Continuity Camera / Sketch / Scan capture.
- **Security**: workspace-scoped filesystem IPC, SSRF-hardened outbound HTTP, `sqlite3 -readonly`, cross-device rename fallback, secure temp directories, backend-owned transform trust store, DNS-rebinding-hardened OAuth callback.

## Install

**macOS (Apple Silicon or Intel)**: download `NEditor_0.2.0_universal.dmg`, drag NEditor to Applications, launch.

This is an **unsigned build**. macOS Gatekeeper will refuse the first launch. Right-click the app, choose Open, confirm.

Signed and notarized artifacts arrive with 0.2.0.

## Verify

```
shasum -a 256 NEditor_0.2.0_universal.dmg
```

Expected hash lives in `SHA256SUMS` attached to this release.

## Homebrew

```
brew tap nyimbi/neditor
brew install --cask neditor
```

(Tap goes live alongside this release.)

## Known limitations

- Unsigned macOS build; Gatekeeper prompt on first launch.
- Windows and Linux artifacts land with the hosted release-publish workflow once signing secrets are in place.
- Auto-updater plugin registered but pointed at a placeholder endpoint pending signing.
